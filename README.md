# 🛒 Shree E-Commerce Website

A simple Full Stack E-Commerce web application developed as a **college project**. The application allows users to browse products, log in, add products to the cart, and place orders through a simple and user-friendly interface.

---

## 📌 Features

* User Login
* Product Categories
* Add to Cart
* Buy Products
* Shopping Cart
* Order Management
* Responsive User Interface
* Backend Integration
* MySQL Database Connectivity

---

## 🛠️ Technologies Used

### Frontend

* CSS3
* JavaScript

### Backend

* Java
* Spring Boot
* Maven

## ▶️ How to Run

1. Clone this repository.
2. Open the backend project in your IDE.
3. Configure the MySQL database.
4. Update database credentials in the application configuration.
5. Run the Spring Boot application.
6. Open the frontend in your browser.
7. Explore the application.
